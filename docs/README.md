# Tula - Tienda Virtual de Cocina Artesanal

## Descripción del Proyecto

Tienda virtual para "Tula", un negocio de comidas elaboradas y productos preelaborados con el lema **"Yo la hago y tú la disfrutas"**.

---

## Estructura del Proyecto

```
/
├── index.html          # Página principal
├── css/
│   └── styles.css      # Estilos del sitio
├── js/
│   └── main.js         # Funcionalidad JavaScript
└── docs/
    └── README.md       # Esta documentación
```

## Secciones de la Página

### 1. Inicio
- Hero con mensaje principal y slogan
- Botones de navegación a categorías
- Productos destacados del día
- Sección "¿Por qué elegir Tula?"

### 2. Comidas Elaboradas
- Menú de platillos listos para consumir
- 5 productos de ejemplo con precios
- Tarjetas con imagen, descripción y botón de agregar

### 3. Preelaborados
- Productos semi-preparados para cocinar en casa
- 5 productos de ejemplo
- Indicadores de conservación (congelado/refrigerado)

### 4. Bebidas
- Bebidas naturales y refrescos
- 5 productos de ejemplo
- Indicadores de tamaño/porción

---

## Componentes Principales

### Header
- Logo de Tula (recreado con CSS/tipografía)
- Navegación principal con 4 pestañas
- Barra de búsqueda
- Carrito de compras con contador

### Footer
- Logo y descripción del negocio
- Información de contacto (teléfono, email, dirección)
- Horarios de atención
- Enlaces a redes sociales

### Botón WhatsApp Flotante
- Posición fija en esquina inferior derecha
- Popup con mensaje de bienvenida
- Enlace directo a WhatsApp Business

## Personalización Pendiente

### Para completar el sitio:

1. **Logo**: Reemplazar el ícono CSS por el logo real en formato SVG/PNG
2. **WhatsApp**: Agregar número de empresa en `href="https://wa.me/TUNUMERO"`
3. **Redes Sociales**: Actualizar enlaces en el footer
4. **Datos de Contacto**: Reemplazar información ficticia
5. **Imágenes**: Reemplazar imágenes de Unsplash por fotos reales de productos
6. **Precios**: Actualizar precios reales de cada producto
7. **Productos**: Modificar nombres y descripciones según el menú real
